Motor de Conciliación de Transacciones Asíncronas

Para resolver los problemas de bloqueo de concurrencia en la base de datos PostgreSQL principal, diseñé un backend desacoplado que utiliza una cola de Redis como capa de retención de transacciones. Los workers asíncronos consumen lotes idempotentes mitigando los p99 de latencia por completo. 

01 async function reconcile(tx: Transaction): Promise<Result> {
02   const isIdempotent = await redis.set(`idemp:${tx.id}`, '1', 'NX', 'EX', 60);
03   if (!isIdempotent) return Result.DUPLICATE;
04   return await db.transaction(async (ctx) => process(ctx, tx));
05 }
